The rig's state lives inside Elasticsearch and in the bucket, not in
anything Kubernetes tracks. `helm uninstall` alone does not prove the
bucket is empty; check the teardown job's own output, which names the
`oci os object bulk-delete` command to run by hand if anything is left.
